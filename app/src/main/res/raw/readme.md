# Аудиофайлы медитаций

В эту директорию нужно добавить следующие аудиофайлы:
- morning.mp3 - Утренняя медитация
- sleep.mp3 - Медитация для сна
- breathing.mp3 - Дыхательные практики

Формат файлов: MP3
Рекомендуемое качество: 128-192 kbps

Примечание: Имена файлов должны содержать только строчные буквы латинского алфавита (a-z), цифры (0-9) и знак подчеркивания (_).
